# BGTech Consulting

Landing page estática, sem dependências ou etapa de compilação. HTML, CSS e JavaScript; esfera 3D projetada em Canvas, movimento por ponteiro, cartões com inclinação, animações de entrada e formulário que abre WhatsApp. Respeita preferência de movimento reduzido.

## Executar

Na pasta do projeto, execute `python3 -m http.server 8000` e acesse http://localhost:8000. Também é possível abrir index.html diretamente.

## GitHub e Vercel

1. Crie um repositório chamado `bgtech-consulting` no GitHub.
2. Envie o conteúdo desta pasta para a raiz do repositório, mantendo a pasta assets.
3. No Vercel, escolha Add New > Project e importe esse repositório.
4. Framework Preset: Other. Sem Build Command; Output Directory: `.`.
5. Clique em Deploy. Futuras alterações enviadas à branch de produção geram novas publicações.

## Alterações

- Textos e serviços: index.html.
- Cores, tamanhos e responsividade: styles.css.
- Animações e WhatsApp: app.js.
