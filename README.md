# BGTech Consulting

Site oficial da **BGTech Consulting** — sites profissionais, sistemas sob medida, automações com IA, consultoria em tecnologia e suporte.

## Estrutura

- Página institucional e formulário integrado ao WhatsApp
- Seis modelos navegáveis: odontologia, advocacia, contabilidade, estética, restaurante e educação
- Layout responsivo para computador e celular
- Animações com suporte a preferência de movimento reduzido
- Contatos oficiais da BGTech Consulting

## Executar localmente

Na raiz do projeto:

```bash
python3 -m http.server 8000 --directory dist
```

Acesse `http://localhost:8000`.

## Publicação no Vercel

O projeto é estático e não possui etapa de compilação. O arquivo `vercel.json` define `dist` como diretório de publicação. A branch de produção é `main`.
